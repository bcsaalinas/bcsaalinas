<p align="left">
I’m Alberto Cisneros Salinas 🎓 — I build web products end-to-end: <b>design → motion → backend → deploy</b>.<br/>
I care a lot about how things <i>feel</i>: smooth interactions, clean structure, and performance that doesn’t get in the way.<br/>
I’ve shipped full-stack projects with <b>React / Next.js</b>, <b>Node.js / Express</b>, <b>PostgreSQL</b>, and I use <b>GSAP + Barba.js</b> for transitions that actually feel alive.<br/>
I also build fast, clean marketing sites in <b>Webflow</b> when iteration speed matters.<br/><br/>
Besides web dev, I’m comfortable with <b>C++</b>, <b>Python</b>, <b>Java</b>, and <b>Go</b> — and I genuinely enjoy optimizing + understanding systems deeply.
